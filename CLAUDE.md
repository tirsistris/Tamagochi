# CLAUDE.md

Тамагочи: существо живёт на странице, реагирует на заботу, напоминает о себе.
Одноразовый репозиторий под тестовое. Срок — 90 минут. Приоритет: одна законченная вещь важнее пяти начатых.

## Жёсткие правила

- Один файл `index.html`. Ноль зависимостей, ноль сборки, ноль npm, ноль CDN.
- Ванильный JS. Никакого React, Tailwind, GSAP, библиотек анимации.
- Существо рисуется SVG-примитивами (ellipse, circle, path, rect). Никакого растра, никаких спрайтов, никакого пиксель-арта.
- Движение — только CSS `transition` и `@keyframes`. Пружины и отскок задаются `cubic-bezier`.
- Один трогаемый участок на итерацию. Никаких «заодно поправлю рядом».
- Не менять уже настроенные константы (тайминги, коэффициенты распада, кривые) без явной просьбы.
- Вместо «готово» — сказать, что именно проверил и что увидел.

## Архитектура

Состояние ничего не знает о внешности.

```
state = { fed, mood, lastSeen, idle, stage, creature }
CREATURES = {
  cat:    { label, palette, svg(state), lines{...} },
  rabbit: { label, palette, svg(state), lines{...} }
}
```

- Вся логика (распад, пороги, лестница внимания) работает только со `state`.
- Добавить третье существо = добавить одну запись в `CREATURES`. Ни строки в логике.
- Переключение существа НЕ сбрасывает состояние. Это то же существо в другом теле.
- `lines` — реплики под каждое событие: поел, сыт и отказался, поиграли, погладили, поднял взгляд, зовёт. Характер задаётся репликами и движением, а не деталями рисунка.

## Существа

Два. Кот — основной, кролик — второй. Оба целиком из примитивов: эллипсы, круги, треугольники, `path` для хвоста и рта.

**Кот.** Экран тёплый и светлый: фон `#FAF2E6`, рамка `#E8DCC8`. Корпус `#F3B183`, живот `#FBE3CC`, щёки и внутренность ушей `#F5A3A3`, глаза и рот `#4A3728`, усы `#D9C3A8`. Тело — эллипс, голова — круг, уши — треугольники, хвост — `path` со скруглённым концом. Характер держится на движении: медленное дыхание корпуса, махи хвостом, прыжок с отскоком. Настроение читается по хвосту (замер — плохо), линии рта и раскрытию глаз.

**Кролик.** Экран тёмный, отсылка к «Матрице»: фон `#06110C`, рамка `#16382A`, контур `#35C47A`, заливка `#0E2A1E`, глаза `#7DFFB8`. Редкий фон из падающих глифов, приглушённый. Тело и голова — эллипсы, уши — два вытянутых скруглённых прямоугольника, слегка разведённых. Настроение читается по ушам: бодрые вверх, поникшие — вниз и короче. Ест не еду, а падающую строку кода.

Палитра живёт внутри записи существа. Глобальных цветовых переменных страницы нет — при переключении меняется только фон «экрана», вёрстка вокруг не трогается.

**Реплики.** Короткие, одна фраза на событие, без восклицательных знаков и сюсюканья, о существе в третьем лице: «Отвернулся. Он сыт». Пишутся по ходу сборки, не заготавливаются.

## Продуктовые инварианты

1. Часы идут без пользователя. `lastSeen` в `localStorage`; при загрузке распад применяется разом за пропущенное время.
2. Смерти нет. Худшее состояние — остыл и спит, но дождался.
3. Эскалация замерзает, пока человек занят: движение мыши, ввод, активная вкладка — таймер простоя стоит.
4. Лестница зова строго такая: тишина → поднял взгляд (только глаза) → одно движение → смена `title` вкладки, если она неактивна. Дальше ничего.
5. Никогда: звук, модальное окно, красный бейдж, счётчик несделанного, любое подобие вины.
6. Кнопка «погладить» не меняет ни одной шкалы. Только реакция.
7. Кормить сытого — отказ и минус к настроению.

## Не делать

Имя существа, эволюция, уровни, XP, третье существо, магазин, кастомизация, режим сна, уборка, звук, бэкенд, аккаунт, тёмная тема, адаптив сверх «на ноутбуке не разъезжается».

Если появляется идея вне этого списка — сначала сказать вслух, что она отрезана, и почему.

## Готово, когда

- Два состояния существа видно на экране без чтения цифр.
- Действия игрока меняют состояние.
- После простоя существо напоминает о себе.
- Открывается по живой ссылке, не на localhost.

## Порядок

| Минуты | Что |
|---|---|
| 0–15 | Скелет: состояние, распад, две шкалы, три кнопки. Существа ещё нет |
| 15–40 | Кот целиком: SVG, реакции, реплики |
| 40–55 | Пуш и проверка на живой ссылке |
| 55–75 | Кролик второй записью в `CREATURES` + переключатель |
| 75–85 | Лестница внимания и заморозка в потоке |
| 85–90 | Показать целиком, назвать шаг на завтра |

Кролик — единственный пункт, который можно вырезать целиком, если время уходит. Вырезать вслух.
